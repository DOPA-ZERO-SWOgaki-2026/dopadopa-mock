# DopaDopa Android App

This folder contains an Android app project for the DopaDopa concept app.

## Requirements
- Android Studio Ladybug or newer
- JDK 17
- Android SDK 34

## Open in Android Studio
1. Open Android Studio.
2. Choose "Open an existing project".
3. Select the `android-app` folder.
4. Let Gradle sync finish.
5. Run on an Android emulator or connected device.

## Notes
This project is a native Android implementation built with Jetpack Compose and is intended to be installed as a real Android app rather than a browser-based web app.
